# go-fiber-csrf

This project is an experimental study using the built-in CSRF protection middleware of [Fiber](https://gofiber.io/). The main goal is to observe CSRF behavior and test API endpoints, with API collections managed and tested using [Bruno](https://www.usebruno.com/).

## Features

- Integrates Fiber's built-in CSRF middleware
- Provides sample endpoints for CSRF testing
- API requests and collections designed for use with Bruno

## Usage

1. Clone the repository.
2. Install dependencies and run the Fiber server.
3. Use Bruno to import the API collection and test CSRF-protected endpoints.

## Disclaimer

This project is for experimental and educational purposes only.
